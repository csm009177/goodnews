# GOODNEWS MISSION ONEAPP 프로젝트

- 목적 : 선교회 특화 통합된 원앱
- mvp : 성경, 찬송가, 내영의노래 + 합창단을 위한 기능

## 공통

- 캐시 허용 물어보기 (앱 실행 후 딱 "최초 1회"만)

## 성경책 페이지

- 기본 성경은 개역한글 FIX
- 영문 성경은 KJV FIX

## 찬송/내영의노래 페이지

- 1단계: 현재 악보가 기기에 있는지 검사
- 2단계: 없으면 사용자 기기에 몰래 캐싱하기

## 일정/공지 페이지

- 바디 최상단에 공지섹션
    1. 디폴트값 : 접기/스위퍼
    2. 공지 고정 기능
- 달려 / 스트림 보기 모드
- 일정 생성/수정/삭제 기능

## 악보 페이지

- 1단계: 현재 악보가 기기에 있는지 검사
- 2단계: 없으면 사용자 기기에 몰래 캐싱하기
